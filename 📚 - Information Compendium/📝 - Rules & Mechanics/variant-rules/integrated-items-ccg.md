# Integrated Items
*Source: Crystalpunk Campaign Guide p. 73* 

Some [Upgrades](/📚%20-%20Information%20Compendium/lists/list-optfeaturetype-eu.md) from the Arm Augmentation^[Optional features from [Evolutionist Augmentation](/📚%20-%20Information%20Compendium/lists/list-optfeaturetype-ea.md)] allow you to integrate items into your arms. While integrated, you can retract and extend the item at will (no action required), unless the item is a shield, in which case it takes an action. You still have a hand, but it is not considered free while these items are extended. If the item is a weapon with the twohanded property, you must still use your other hand to make an attack with it. Lastly, you can only have one integrated item in each arm.
