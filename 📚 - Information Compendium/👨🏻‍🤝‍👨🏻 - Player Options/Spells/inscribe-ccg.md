# Inscribe
*cantrip, Illusion*  


- **Casting time:** 1 Action
- **Range:** Touch
- **Components:** V, S
- **Duration:** Until dispelled

This spell inscribes a runic message on a surface you touch, which glows dimly in a 1-foot radius. The message can be 25 words or less. If multiple messages created by different casters are inscribed within 5 feet of each other, they each appear as distinctly different colors, one for each caster. When you inscribe a message, you can choose for it to be visible in either the Material Plane or Ethereal Plane. Also, you can choose for it to be hidden. If you do, the message is invisible to all creatures except for those who know this spell.

*Source: Crystalpunk Campaign Guide p. 110*
