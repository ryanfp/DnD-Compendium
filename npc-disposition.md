# NPC Disposition

## Levels


| Number | Disposition | Description |
| ------ | ----------- | ----------- |
| -2     | Hostile     |             |
| -1     | Wary        |             |
| 0      | Neutral     |             |
| +1     | Polite      |             |
| +2     | Friendly    |             |

NPC starts at 3 Interest and 3 Patience, Disposition gives a bonus to allocate points towards either Interest or Patience (add 2 to Patience for a total of 5, or 1 to Patience and Interest to a total of 4 each).

Interest and Patience run on a track of 0-6 (with 1-5 onyl )
